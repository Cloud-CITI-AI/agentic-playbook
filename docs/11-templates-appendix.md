# 11. Templates appendix

All templates are production files in `templates/`. This index states what each is for and where it lands in an adopting repo. Mode per `templates/manifest.txt`: **managed** (kept in sync), **seed** (copied once, then owned by the repo), **append** (managed header, repo-owned entries).

| Template | Path in playbook | Lands at | Mode |
|---|---|---|---|
| PR template | `templates/project/.github/pull_request_template.md` | `.github/pull_request_template.md` | managed |
| Issue forms: agent task, bug, feature, config | `templates/project/.github/ISSUE_TEMPLATE/` | `.github/ISSUE_TEMPLATE/` | managed (config: seed) |
| Agent task brief (markdown version) | `templates/agent-task-brief.md` | pasted into issues | — |
| ADR template | `templates/project/docs/adr/0000-template.md` | `docs/adr/0000-template.md` | seed |
| CHANGELOG format | Keep a Changelog, generated by release-please; config `templates/project/release-please-config.json` | root | seed |
| LESSONS entry format | `templates/project/LESSONS.md` | `LESSONS.md` | append |
| CODEOWNERS | `templates/project/.github/CODEOWNERS` | `.github/CODEOWNERS` | seed |
| Starter workflows: ci, security, release, deploy, playbook-guard, playbook-sync, lessons-digest | `templates/project/.github/workflows/` | `.github/workflows/` | mixed (see manifest) |
| Reusable workflows | `.github/workflows/reusable-*.yml` | called by SHA | — |
| Security checklist (fillable) | `templates/project/docs/security-checklist.md` | `docs/security-checklist.md` | managed |
| Definition of ready / done | `templates/project/docs/definition-of-done.md` | `docs/definition-of-done.md` | managed |
| Root / package AGENTS.md, CLAUDE.md, Copilot instructions | `templates/project/`, `templates/<profile>/` | root, package dirs | managed |
| Claude Code settings + protection hook | `templates/project/.claude/` | `.claude/` | managed |
| Renovate, `.npmrc`, pnpm snippet, lefthook, gitignore snippet | `templates/project/` | root | seed |
| Test configs (Vitest, Playwright, Stryker, pytest/ruff/mypy, Makefile) | `templates/<profile>/` | package dirs | seed |
| Worked test examples | `templates/<profile>/examples/` | reference only | — |
| Rule proposal template | `rule-proposals/README.md` | playbook repo only | — |
